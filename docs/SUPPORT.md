# Support content source

Support answers are maintained in `apps/web/src/content/support.ts` and rendered at `/support`. They supersede the original support draft.

Public contact: **Suhel Makkad — makadsuhel11@gmail.com**.

Canonical URL reserved for publication: **https://nextbell.org/support**. This implementation is local; the page becomes publicly available only after website deployment.

Topics include setup, hidden/shared/subscribed calendars and permissions, the three calendar modes, busy-only access, reminder inheritance, task alarms and queued completion, alarm troubleshooting, force-stop behavior, offline refresh and timezone travel. Data-removal steps are maintained in `apps/web/src/content/policies.ts` and rendered at `/data-deletion`.

Before publication, confirm the mailbox is monitored, the instructions match the released app, and the pages are publicly reachable. Ask users for an OS/app version and non-private reproduction; never request tokens, passwords or private meeting contents.
